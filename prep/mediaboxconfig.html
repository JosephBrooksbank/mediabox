Welcome to Mediabox!

Basic Information & Configuration

  • Change VPN Location: if you would like to change your VPN location run the ./change_vpn.sh script in the Mediabox directory.
  • The Filebrowser login is: admin / admin.
  • PROXY The DelugeVPN Container provides an http proxy via the PIA connection at: locip:8118

Manual Configuration steps:

Prowlarr:
  • Add your indexers under Indexers
  • If an indexer is behind Cloudflare, add FlareSolverr under Settings > Indexers: http://locip:8191
  • Under Settings > Apps, add Radarr (http://locip:7878) and Sonarr (http://locip:8989) using their API keys

Radarr:
  • Click on the Settings icon
  • Click on the Download Client Tab
  • Click on the + sign to add a download client
  • Under the "Torrent" section Select Deluge
  • Enter these settings:
    * Name: Deluge
    * Enable: Yes
    * Host: locip
    * Port: 8112
    * Password: deluge (unless you have changed it)
    * Category: blank
    * Use SSL: No
  • Optional: Click on the media management tab and configure the renamer

Sonarr:
  • Same instructions as Radarr

Profilarr:
  • Connect Radarr and Sonarr using their URLs and API keys to sync quality profiles and custom formats

Bazarr:
  • Under Settings > Sonarr and Settings > Radarr, connect each using host locip and their API keys

Seerr:
  • Sign in with your Plex account and connect Plex (locip:32400), Radarr, and Sonarr

PLEX:
When adding libraries to PLEX use the folders under /data/merged.

Container Updates

Watchtower:
The Watchtower container monitors the all of the Mediabox containers and if there is an update to any container's base image it updates the container.
Watchtower will detect the change, download the new image, gracefully stop the container(s), and re-launch them with the new image.
